# 支线任务素材库

这个库存的是"玩家们真的在玩、玩了会发笔记"的玩法，提炼自小红书等 UGC 平台。你在 S1 构思支线时，从这里借机制、借种子，改成合身玩家此刻条件的方案。

## 怎么用（重要）

1. **先选机制，再挑种子**：机制是创意引擎，能无限生出新任务；种子是已经被验证好玩的具体玩法。优先想"哪个机制配玩家此刻的处境"，再从对应场景里挑种子改写。
2. **禁止原样照抄**：种子里的标题和玩法是公共素材，直接端出来等于抄袭网友。至少改两层：换玩家本地的具体对象（哪条街、哪家店、家里的哪样东西），换一个贴合玩家情绪的切口。
3. **按标签硬筛**：每条种子尾部带标签〈机制·类别·时长·场景·人数·预算·体力·人群·新意〉，先过硬约束（时长≤空闲80%、场景、人数、预算、体力），不符的直接跳过或改造。
4. **一次一组支线要有机制差异**：2-4 个活动不要全用同一机制（比如三个都是"收集图鉴"），至少跨两种机制；类别（探索/整理/创造/连接/感官）也尽量错开。
5. **人群与新意标签是提示不是限制**：标了 i 人的种子通常不用搭话、社恐友好；标了情侣/祖孙的更适合双人陪伴场景（祖孙=陪爷爷奶奶、外公外婆、姥姥等祖辈的跨代际玩法，节奏慢、重听故事和一起动手）；标了亲子的是带娃视角，别和祖孙混用；新意 3 是脑洞陌生化玩法，一组里最多放一个，其余用新意 1-2 兜底稳妥感。
6. **种子目录在本手册末尾由系统一并注入**，按场景分组、每条一行，直接按标签检索即可；不需要（也不应该）凭记忆复述种子。

## 一、十大玩法机制（创意引擎）

1. **随机委托**：把决定权交给硬币、骰子、随机数——来什么车坐什么、路口猜拳左右、地图上闭眼点一个位置、便利店随手拿。治的是选择内耗，"替我做决定"本身就是乐趣。
2. **收集图鉴**：定一个主题，出门集齐 N 个——一种颜色、一种形状、五种声音、三只猫。给散步和逛街一个钩子，凑齐的瞬间有爆装备感。
3. **视角重赋**：给寻常物一个新身份——芒果核养出"芒狗"、肥皂盘出包浆、超市水产区当海滩赶海、给路人编背景故事、看蚂蚁写《蚁族职场报告》。荒诞感是核心，越一本正经越好笑。
4. **规则限制**：给平常事加一条奇怪约束——用一半速度走路、一个圆只能加三笔变东西、做饭只用冰箱现有存货、绕一条从没走过的路。限制逼出注意力。
5. **定点观察**：固定一个位置，记录变化或细节——同一条回家路每天找一个不同、窗边站五分钟、看云十分钟。门槛最低，治愈感来自"原来我周围有这么多东西"。
6. **触感心流**：重复的手部动作让脑子关机——拼豆、钩织、刮肥皂、折纸、整理一个抽屉、鞋带系出新花样。适合"有点累、不想动脑"。
7. **盲盒猜谜**：主动屏蔽一种感官或信息，靠猜完成——蒙眼尝味、闭眼摸物猜物、闻香起名、冰淇淋猜配料。猜错的反差就是笑点。
8. **角色扮演**：换一个身份做平常事——特工接头、城市副本通关、探店对暗号、寻宝 NPC、客厅室内野餐。游戏框架让普通动作有了剧情。
9. **连接动作**：发起一次微小的人际接触——给三个月没联系的朋友发句"刚看到个东西想起你"、请路人帮忙拍照、教同伴一句家乡话。社交压力要小到能开口。
10. **留痕收尾**：产出一件可回看的证据——前后对比照、压花标本、10 秒环境音录音、给未来自己的信、一张菜谱卡。收尾感决定"这事我真做过了"的实感。

## 二、改编示范（种子怎么变成玩家的支线）

种子「声音地图」的三种合身变体：

- **15 分钟 / 在家 / 有点累**：不开窗，就坐床边听 3 分钟，数出房间里几种声音即可，不找来源、不记录——只剩"注意听"这一个动作。
- **30 分钟 / 在街上 / 一个人 / 想找点新鲜**：在街边长椅闭眼听 3 分钟，记下 5 种声音，挑最怪的一个走过去找到它是什么，拍一张声源的照片。
- **和朋友一起 / 店里**：两人各自闭眼听 3 分钟写下来，交换清单——谁听到了对方没听到的声音，谁赢一杯饮料。

改编要点：**机制不变（定点听+计数），约束跟着玩家的时长/体力/人数伸缩，最后留一个符合场景的收尾动作**。

## 三、素材来源

本库玩法提炼自对真实 UGC 内容与媒体报道的调研（2026-09）：
1. 小红书《太好了！是没用的兴趣展》相关报道与复盘（养芒狗、盘肥皂、超市赶海、工位养宠、落叶调色盘、包装纸收集等"无用兴趣"）。
2. 深圳卫健委《50 件低成本的快乐小事，适合一个人做》。
3. 什么值得买聚合文《低成本高快乐：这些爱好一试就上瘾》（拼豆、钩织、阳台种菜、绿道骑行等）；"手搓"热潮追踪报道（拼豆声量一年涨约 60 倍、扭扭棒"植物精灵"、造景贴纸、3D 打印）。
4. 北京青年报《慢节奏"老派爱好"正在年轻人中集体复活》。
5. 中国新闻网/北京青年报《年轻人出游有多会玩》（随机公交、Color Walk、Shape Walk）。
6. 都市快报《杭州年轻人沉迷的 City Walk》（路口猜拳决定方向）；各地"免费地标+CityWalk"路线与集章通关文牒玩法（小红书马路生活节等）。
7. 梧州共青团"盲盒 CityWalk"、华声在线/三秦都市报"City walk+剧本杀"报道。
8. 各地文旅游戏化玩法（绍兴"副本"、镇江"SBTI"通关文牒、上海淡水路 Flower Walk 护照打卡、城市透卡）。
9. 情侣/双人/聚会现实互动游戏合集（三真一假、背后画画、故事接龙、数字炸弹、禁词挑战、路人职业竞猜等）。
10. 低成本爱好与 micro-hobbies 相关公开内容（抽屉整理、摘抄、白噪音、工位拉伸等）。
11. 年轻人"精神疗愈空间"趋势（花鸟市场/花市治愈、寺庙游与抄经、2 元公交环线漫游、公园 20 分钟效应、博物馆找萌文物）。
12. 手工新材料趋势（扭扭棒、石塑黏土、火漆印章、奶油胶、数字涂色、戳戳绣、蓝晒/植物拓印、橡皮章）。

给玩家呈现时不要提及"这个玩法来自某平台"——支线是小闲从任务板上挑出来的，不是刷到的帖子。
