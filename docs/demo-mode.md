# 演示模式

演示直接部署在现有托管产品中，通过开关切换；无需另开服务或单独维护一份代码。

## 进入与退出

- 普通页面右下角有一个小圆点，点击后打开演示设置。
- 键盘快捷键：`Alt+Shift+D`。
- 直接打开：在产品地址末尾加 `?demo=1`。
- 演示时右下角显示「演示」徽标，点击后可跳转各功能，或关闭演示模式。
- 「重置演示」重新载入初始示例，方便下一场展示。

## 一条无需输入的演示路径

1. 开启模式，在控制台点「开始体验」，展示对话推荐；点击「换一批」展示另一批任务。
2. 选择任务卡片，进入以步骤为主的任务页。「任务体验」也可直接跳到第一步。
3. 点「问问吱呀」→「演示：问问做法」，演示辅助对话；回到任务时进度不变。
4. 每步点「填入示例记录」或「填入示例照片」，再提交，直到任务完成。
5. 打开「任务地图」，展示放松、惊喜、表达、连接、成长；点节点看原始作品，点主题看跨方向的发展关系。
6. 打开「偏好画像」→「喜好配置拟合」→「查看已保存画像」。可回看全部 30 组答案。
7. 打开「心愿计划」→「做一本自己的日常声音小册」→「今天想推进一点」，完成已有计划的下一章，再查看进度与纪念章。
8. 打开「灵感收藏」，点「填入示例灵感」→「让吱呀整理」→「收藏这条灵感」。可展示暂停或恢复推荐。
9. 控制台的「日常记录」「新手教程」可直接切换到相应页面。

初始数据包括 15 条完成任务及作品、2 条跨方向主题、完整 MBTI 与宏观喜好、30 组问卷和拟合画像、进行中／草稿／已完成三份心愿、3 条灵感。演示操作会保留，刷新后可恢复当前任务。

## 数据边界

演示的档案、会话、草稿和运行状态统一写入 `xian.demo.` 命名空间，普通模式沿用原有键。切换时整页重载，避免已挂载状态混用；重置不清理普通模式的数据。

同源业务 API 全部由本地演示运行时处理，未知接口返回明确错误，不能回退到真实后端。演示照片使用本地样例图；不会上传相册文件、调用付费模型或请求定位和麦克风。朗读使用浏览器设备语音，可用性取决于设备，无法朗读时仍可看字幕。正式模式继续使用原有后端和语音服务。

## 验证

- `npm run test:demo`：运行时测试，覆盖任务、照片、辅助聊天、刷新恢复、重复提交、心愿与奖励、主题及灵感变更、请求中止。
- `npm run test:demo:ui`：连接共享浏览器，使用独立浏览器上下文；覆盖完整演示、重置退出、普通模式草稿保留，并确认演示没有发出真实 API 请求。
- `npm run test:threads` 与 `npm run test:threads:ui`：方向归类、单节点、多主题连接、旧数据兼容和地图交互回归。

界面检查包含 320×568、375×812、844×390、1280×900。自动化不会写入真实用户档案；不替代真实模型质量和物理手机能力的验收。
