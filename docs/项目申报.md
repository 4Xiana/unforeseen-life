# 项目申报

## 作品名称（10字以内）

支线任务

## 灵感来源（100字以内）

通勤间隙总被短视频吞掉，回头却想不起刚才做了什么。希望用一条条「支线」把碎片时间变成可被记住的小确幸——生活有主线，快乐在支线。

## 解决方案（100字以内）

前端 React + Vite + Tailwind，后端 Express + TypeScript，接入 DeepSeek API 做智能推荐与验收。最大挑战是杜绝「点确认即完成」，为此设计了独立 AI 证物审核员作为硬门控。

## 最惊艳的地方（100字以内）

① 防耍赖验收——每步必须交文字/照片证物，AI 结构化判定 pass/reject，驳回保留输入引导重交；② 喜好拟合——Pair-wise PK 精准建模用户偏好并加权推荐；③ 沉浸模式——语音通话式交互+字幕；④ 支线记录页——每步证物完整留存可回放。
