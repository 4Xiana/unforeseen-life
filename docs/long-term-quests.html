支线任务 / 产品迭代 / 2026.11.05

让每次出发，都有一点积累。

长程支线：把一个长期愿望拆成能在闲暇里完成的小章节，接着上次的发现继续，最终留下自己的成果。

生活有主线，快乐在支线。以下演示为交互示意数据，不代表用户已有进度。

为什么做

用户反馈目前的任务缺少意义。本轮优先解决“一次性任务缺少长期积累”，将创意库整体升级留到下一轮。任务不仅需要属于某个目标，还必须用得上前面的成果，并让用户看见自己正在积累什么。

保留现有长期喜好档案，用它描述“我喜欢什么”；新增长程目标，描述“我想慢慢做成什么”。两者分开保存，共同影响任务推荐。目标建立是自愿入口，不阻断第一次使用。

设定愿望与偏好 → 预览章节计划 → 用户确认 → 日常推荐偶遇 / 主动推进 → 提交证物并验收 → 章节留痕、解锁后续 → 成果手账与纪念章

FR-01 · 设定一个愿望

首页与聊天工具区通过统一的「我的手册」入口进入「喜好 / 心愿计划 / 日常记录」三个栏目，在「心愿计划」中设定愿望。栏目切换保留正在填写的内容。用户可以选择示例方向，也可以自由输入目标。示例只填入表单，不生成虚假的完成记录。

字段行为
愿望 / 成果必填。用户描述想积累的能力、作品或体验，例如“用手机拍出一本自己的街区相册”。抽象目标通过拆解预览具体化，不擅自承诺掌握专业能力。
为什么想做可选。用于调整主题与反馈，不要求用户表达宏大意义。
长期喜好与雷点沿用现有档案；本目标可补充兴趣、可用材料与限制。没有填写时不编造器材、地点或预算。
通常能留出的时间、场景用于设计小章节；实际推荐仍以本次时长和场景为准。

产品默认值 [Assumption, TBD]：每个目标先规划 3–6 个章节；每章是一项碎片任务，包含 2–4 个需要证物的步骤；默认零额外花费。先让用户看到一个能完成的阶段性成果，不一次排满数月日程。

街区相册 · 四个小章节

  1. 选一个熟悉的街角，留下第一张照片与观察。
  2. 沿用那个街角，换一个角度再拍并对比。
  3. 从前两次照片选一个主题，补拍一组细节。
  4. 从已有作品挑选照片，写下标题与图说，组成相册。

生成失败保留输入并允许重试，不能把套用无关模板的结果标成个性化拆解。用户确认前为草稿，不进入推荐；确认后保存章节与目标。已经开始的计划先保持版本稳定，目标改变时可暂停旧目标并建立新目标，原有证物不覆盖。

FR-02 · 随机出现，有序推进

每批普通推荐中可以混入一项长程章节。随机发生在“是否出现、从哪个符合条件的目标中选”，不发生在章节顺序上。只允许推荐该目标已解锁的下一章，已完成章节不重复计进度。

产品默认值 [Assumption, TBD]：符合条件时，每批以 50% 概率混入至多 1 项；至少保留 1 项普通任务。刚展示过的同一章节设置 20 分钟冷却，避免用户换一批仍然收到同一项。用户从长程页面主动选择「这次推进它」时不受随机和冷却限制，仍检查本次时间及场景。

  • 时间不足、场景不符、目标暂停或已完成：本次不混入，不能把较长任务强行压短。
  • 未选择、换一批或放下当前章节：不扣进度，下次仍可从该章继续。
  • 多个目标符合条件：从符合条件的下一章中选择，避免一个目标占满推荐。
  • 卡片标出目标名称、章节序号、这次积累的成果，以及与上次的关联；用户知道自己正在推进什么。

FR-03 · 每一章都用得上前一章

拆解需要明确每章的产物，以及后续会怎样使用它。首章建立基线或收集素材；中间章节围绕已完成的内容练习、补充或比较；最后一章整理为成果。避免仅把相似的独立任务编号后排列起来。

执行时，吱呀读取上次的真实记录：例如用户上次拍的是“蓝色门牌”，下一章就围绕那张照片换角度、补细节。对话和卡片能查看前序成果；图片只能引用真实保存的照片，无法从文字判断的视觉细节不得编造。

每一步继续采用原有文字 / 照片验收。只有整个碎片任务的证物全部通过，才算完成一个章节；“做完了”的点击或声明不能解锁下一章。任务可跨刷新恢复，网络重试不能重复结算。

FR-04 · 长程手账与专属奖励

「长程」页面按目标展示：愿望、最终成果、已完成章节数、章节地图、下一章和当前状态。展开章节可回看实际指引、原始文字、现场照片与完成日期。未完成章节显示解锁条件，不生成虚假作品。

奖励默认值 [Assumption, TBD]：第一章、完成过半、整条长程完成时分别点亮纪念章。纪念章属于这个目标，与普通任务徽章分开。最终奖励是专属成果页：将用户实际积累的照片、文字与章节串起来，允许下载文字记录；照片继续在成果页查看。奖励不涉及金钱，也不承诺“学会 / 治愈”等未验证效果。

状态可以做什么如何变化
草稿看拆解、返回修改用户确认后进入进行中
进行中偶遇 / 主动推进、回看成果、暂停所有章节完成后进入已完成
已暂停回看成果、恢复不再推荐新章节；暂停前已经接取的任务允许完成并计入
已完成回看、下载记录、建立新目标不因日历时间自动退回，不重复发奖

每个目标及其记录归属于当前用户；不可用其他用户的目标 ID 接取或领取进度。第一版沿用匿名设备身份，同一浏览器可恢复，跨设备登录不在本次新增范围。

本方案中的概率、冷却和章节数量是待实际使用检验的产品判断，并非已验证的最优值。随机偶遇不会替代主动入口，暂停不会删除历史，离开几天不会丢失进度。
