# Design SPEC · 蜡笔手账（Crayon Journal）

## 灵感收藏与声音

- 手册新增「灵感收藏」，使用奶油色纸张、文楷字体、苔藓绿和全圆角按钮。以多行输入接收自己的任务、文章/视频文案和公开链接。
- 整理后先预览，允许修改名称与核心玩法，再确认收藏。草稿保留，失败原位提示；收藏与已完成记录独立。
- 收藏卡显示推荐状态，可回看原文和来源、暂停或恢复推荐；移出前在卡片内确认。
- 推荐卡以「我的灵感」标签说明来源，沿用原有步骤与证物验收。
- 吱呀使用 MiniMax「俏皮萌妹」，通话提供试听、生成中反馈及点击重试，开麦时即时打断播放。

> 风格来源：《椅子上有猫 / Cat on Chair》（Ryan Yao，2025）——手绘蜡笔质感、圆角圆体、暖色陪伴感。
> 调研依据：官网 catonchair.app 实际计算样式 + App Store 六张产品截图。
> 本 SPEC 将该风格与本应用「支线任务」主题融合：手账只作为**视觉隐喻**存在（纸张卡片、胶带、贴纸、蜡笔描边、手写体、手绘椭圆圈），去掉官僚感的直角与暗红，整体转向「蜡笔画出来的手账」。
> **分层约定**：所有可见文案（Agent 对话、阶段手册、stepping 缓冲文案、界面文案）统一使用「开放世界支线任务」语言（支线、出发、收工、交差、任务板），不使用手账词汇（纸签、翻页、盖章、守页人）；吱呀身份是「支线伙伴」，不是守页人。
> **应用名称**：统一为「支线任务」，页面、引导、产品文档和生成提示词保持一致。吱呀是应用内的支线伙伴，不是应用名称。引导文案必须说明使用情境、用户动作和可获得的结果，不以短口号替代功能说明。

---

## 1. 一句话定位

**像用蜡笔在奶油色纸上画出来的界面**——圆、暖、软，有手绘的抖动和贴纸的俏皮，但信息保持清晰。

## 2. 视觉关键词

- 蜡笔质感：填色不均匀、描边有轻微抖动感
- 奶油纸底 + 满铺细颗粒噪点
- 圆体字（圆润手写感）+ 手写体批注
- 大圆角卡片、全圆角胶囊按钮
- 空心描边大数字（计时器/序号）
- 苔藓绿为主色，蜡笔高饱和色为点缀（珊瑚红/橙/蓝/青/粉）
- 贴纸、胶带、手绘圈（马克笔椭圆圈选）作为装饰语言

## 3. 色彩系统

| Token | HEX | 用途 |
|---|---|---|
| `--paper` | `#FDFBF7` | 页面奶油底 |
| `--paper-2` | `#F5EFE3` | 浅纸（输入框底/骨架） |
| `--paper-3` | `#EAE2D0` | 纸面压暗层 |
| `--paper-edge` | `#DED5C2` | 纸边/分割 |
| `--card` | `#FFFFFF` | 卡片白底（浮在奶油上的白卡） |
| `--ink` | `#2D2A26` | 主文字/蜡笔描边（暖近黑，不用纯黑） |
| `--ink-2` | `#5A5349` | 次级文字 |
| `--fog` | `#8B8378` | 弱化文字/占位 |
| `--fog-light` | `#C9C0B0` | 描边/虚线 |
| `--moss` | `#729451` | **主色**：主按钮、进行中、吱呀徽章 |
| `--moss-deep` | `#4F6B36` | 主色上的深字/深绿批注 |
| `--coral` | `#E0685C` | 强调/错误/印章（替代旧暗红） |
| `--orange` | `#F0A03E` | 蜡笔橙：标签/胶带 |
| `--blue` | `#5B8FC9` | 蜡笔蓝：标签/空心数字 |
| `--teal` | `#3FA28F` | 蜡笔青：成功/已完成（替代旧 indigo 的部分场景） |
| `--mint` | `#8FD8BE` | 浅青：完成底纹 |
| `--pink` | `#F2A6B5` | 蜡笔粉：少量可爱点缀 |

规则：
- 一屏内蜡笔高饱和色最多 3 种；绿色是主色，其余只出现在标签、序号、装饰贴纸上。
- 文字只用 ink / ink-2 / fog 三档灰，不用彩色正文。
- 错误/驳回用 coral，成功/完成用 teal。

## 4. 字体系统（三档）

| 档位 | 字体栈 | 用途 |
|---|---|---|
| Display 圆体 | `"ZCOOL KuaiLe", "Baloo 2", "Noto Sans SC", sans-serif` | 标题、按钮、大数字、卡片标题、徽章 |
| Body 正文 | `"Noto Sans SC", Inter, system-ui, sans-serif` | 段落正文、输入内容 |
| Hand 手写 | `"Ma Shan Zheng", "Caveat", cursive` | 批注、副标题、提示语、吱呀署名、引导语 |

规则：
- Display 圆体用于「需要被看到的字」：标题、按钮、数字；正文不用。
- 手写体用于「像在纸边批注的字」：hint、label、时间戳感文字；每条 UI 中手写体不超过两处。
- 等宽字体（JetBrains Mono）仅保留给序号/计时数字的备选，不再用于徽章标签。
- 大数字/序号用空心描边：`-webkit-text-stroke: 2px currentColor; color: transparent`，配 Display 字体。

## 5. 形状与圆角

- 卡片：`20–24px` 大圆角（`rounded-3xl` 级），配合 ±0.5–1.5° 的轻微旋转，保持手绘贴在纸上的感觉。
- 按钮：胶囊（`rounded-full`），无直角按钮。
- 标签：胶囊小药丸（`rounded-full`）。
- 输入框容器：大圆角胶囊（`rounded-full`/`rounded-2xl`）。
- 装饰贴：圆形贴纸（描边 2px）、胶带（小矩形微转）、手绘圈（椭圆描边）。
- 边框：默认 1px 纸边；需要「蜡笔描边」时用 **2px solid ink**（关键按钮、进度环）。

## 6. 质感

- **纸粒**：全局 SVG fractalNoise 噪点，opacity 0.04，multiply，固定不滚动。
- **蜡笔填色**：色块允许轻微不平整感（噪点 + 柔和投影），不使用高反差渐变；高光用左上角柔光。
- **阴影**：暖色调软阴影 `rgba(45,42,38,0.08–0.18)`，模糊 12–28px，偏移 2–8px；主按钮阴影更厚（`0 8px 20px rgba(45,42,38,0.18)`）。
- **贴纸层级**：白卡浮在奶油纸上；胶带/贴纸用更小的阴影或描边制造"贴上去"的层次。
- 禁用毛玻璃/高透明白；模糊仅用于弹窗底遮罩。

## 7. 组件规范

- **NPC 气泡**：白卡（`--card`），圆角 20px，无左侧色条；左上角可露一截胶带；吱呀署名用手写体。
- **用户气泡**：暖橙便利贴（`--orange` 12% 底），圆角 16px，顶部一截胶带。
- **活动卡（纸签）**：白卡圆角 20px，左侧 4px 蜡笔色边（五色轮换），右侧保留票根圆孔；序号用蜡笔色圆形描边徽章；hover 上浮 2px。
- **步骤卡**：白卡圆角 24px + 胶带；进度点为蜡笔描边圆点，当前点 moss 实心带柔光；指令区左侧 4px coral 竖条改为 moss/teal 色；已完成态显示 teal「这一格，已勾上」。
- **主按钮**：moss 底 + ink 文字，胶囊，Display 字体，厚软阴影，按下 scale(0.97)。
- **次按钮**：透明底 + 2px ink/coral 描边胶囊，hover 填浅色。
- **关键动作的强调**：可在按钮/文字后加手绘椭圆圈（SVG，2.5px 蜡笔色描边，旋转 ±5°），替代方框高亮。
- **标签**：胶囊，蜡笔色 12–18% 底 + 同色深字。
- **状态徽章**：圆角胶囊 + 1.5px 描边，手写体小圆点，不用方章。
- **输入区**：白卡大圆角容器；发送按钮为 moss 圆形；图标线宽 1.5–2px 圆头。
- **骨架屏**：paper-2/paper-3 色块，圆角与真实卡片一致（20px）。
- **弹窗（完成屏）**：白卡圆角 28px，厚软阴影；完成标识为 teal 手绘椭圆圈 + Display 字「支线完成」；主按钮胶囊「接下一个支线」。
- **头像**：moss 底圆形（不再是黑底），白色人物/猫脸线条。

## 8. 动效

- 入场：`translateY(16px) → 0` + 淡入，cubic-bezier(0.16,1,0.3,1)，卡片错峰 80ms。
- 打字点：三点 pulse，1.2s。
- 转圈：柔和 spin，配手写体说明。
- 按钮：hover 上浮 1–2px，active scale 0.97。
- 印章/盖章：保留 stampPress（旋转 -12° 弹入），颜色改 moss/teal。
- 缓动统一：弹性用 `cubic-bezier(0.34,1.56,0.64,1)`，常规用 `cubic-bezier(0.16,1,0.3,1)`。

## 9. 禁忌

- ❌ 直角（2px 方角）卡片/按钮、❌ 纯黑 `#000`、❌ 高饱和渐变
- ❌ 客服式阴影分割线堆叠、❌ 毛玻璃卡片
- ❌ 一屏超过 3 种蜡笔强调色、❌ 彩色正文
- ❌ Display 圆体用于长段落、❌ 手写体用于按钮主文案
- ❌ 系统默认字体直出数字（序号/计时必须有圆体或空心处理）

## 10. 移动端尺寸与布局（2026-11）

保留奶油纸、蜡笔色与手写字体。小屏以收紧留白、调整排列为主，任务指引与证物内容保持完整；以下规则优先于前文的桌面尺寸。

| 元素 | 手机端规则 |
|---|---|
| 断点 | `<640px` 为手机布局；`≥640px` 保留桌面排列；触屏设备独立扩大热区 |
| 页面边距 | 对话区 12px；弹层正文 16px；横屏另计左右安全区 |
| 交互热区 | 按钮至少 44×44px；主按钮通常 44–48px 高；图标保持 13–20px |
| 字号 | 输入框与文本域 16px，避免 iOS 聚焦自动放大；正文 14–15px，辅助信息 11–13px |
| 卡片 | 内边距 12px，圆角 16–18px；窄屏取消任务卡和气泡旋转，节省边缘空间 |
| 聊天顶栏 | 品牌图标可返回首页，手册／新一轮／任务进度／沉浸使用 44px 圆形图标入口；手机工具栏靠右排列，不重复放记录入口 |
| 首页 | 常规屏保留大 IP；低于 700px 的可用高度收紧头像与语音按钮；键盘输入模式缩小品牌区，快捷词单独滚动，输入框持续可见 |
| 极矮屏 | 可用高度 ≤500px 时，品牌区改横向紧凑排列；正文独立滚动、底部入口常驻 |
| 手账／记录 | 手机呈底部纸页，标题与关闭按钮固定、正文滚动；长标题换行 |
| 弹层 | 高度继承 App 的可见视口；底部留出 `safe-area-inset-bottom`，关闭与提交入口可达 |
| 喜好对比 | 进度条视觉高度 8px、按钮热区 44px；两张任务卡不被纵向压缩，正文整体滚动 |
| 任务进度 | 8 步以上等长进度点允许局部横向滚动；计时器按钮有独立热区 |
| 轨迹追踪页 | 手机将左侧会话列表改为顶部限高区域，下面独立滚动查看事件 |

实现集中在 `src/index.css` 的响应式规则，以及组件上的语义类名。`App` 将 `visualViewport.height` 同步为 `--app-height`，弹层与页面共用这个高度；容器查询按实际可用高度压缩品牌区。保留双指缩放，不在缩放期间根据缩小的视觉视口重新排版。

验收覆盖首页两种输入方式、喜好表单与时间对比、聊天推荐、文字／照片证物、任务抽屉、计时器、手账、记录、沉浸字幕／卡片、完成页及轨迹追踪页。布局验证可使用拦截 API 的测试数据，避免产生真实任务记录；语音、相机及系统键盘仍需真机验收。

### 语音状态与手势

- 区分启动中、聆听中、整理文字与就绪状态；只有浏览器发出 `onstart` 后才能显示正在聆听。
- 按住说话使用指针捕获，容忍手指轻微偏移；上滑 64px 或系统取消手势时取消录音并恢复原草稿。
- 首页与沉浸模式提供「也可以点击录音／结束并发送」，方便首次授权；键盘激活大语音按钮也采用点击开始／结束。
- 网络、权限、启动及收尾超时必须显示可见提示，保留已识别文字，不因识别失败自动发送已有草稿。
- 所有输入共用麦克风所有权；开始收音即停止 TTS，离开页面释放麦克风。

### 会话恢复交互

- 页面打开时先读取最近会话，显示「正在打开你的支线记录…」，避免首页闪现。
- 有记录时直接恢复聊天及当前任务；不重播完成动画、不重调 Agent、不重复交证物。
- 服务器仍在处理的回复显示同步状态，暂时禁用提交；完成后恢复最新内容。
- 连接失败提供「重新连接」；服务中断保留原始提交，并提示用户继续。
- 顶栏「新一轮」创建新会话；已有记录保留。优先恢复当前选择的会话，没有选择记录时读取最新会话；从长程页续接旧章节后刷新仍留在该章节。
- 聊天左上角品牌图标返回首页，仅切换页面展示，当前任务、对话与回复继续保留。首页提供「继续当前支线」返回聊天；输入新的话仍发送给当前会话。「新一轮」图标仍负责明确创建新会话。

## 11. 我的手册与长程支线

- 首页与聊天统一提供「我的手册」入口，收纳三个页签，移除分散的爱心、长程文字链接和手账按钮。聊天入口使用书本图标，取消独立记录按钮；首页保留手册文字入口，手册标题不添加副标题。日常记录内可展开每条支线查看逐步原始文字与照片证物，旧记录无步骤详情时保留原始证物文本。
- 聊天工具使用书本、新一轮箭头、任务清单和耳机图标，提供 aria-label、title 与键盘焦点。任务状态以小圆点表示，详细进度放在悬停说明与任务抽屉中。
- C 端栏目名称统一为「喜好 / 心愿计划 / 日常记录」。心愿计划表示围绕明确愿望逐章积累的系列任务，日常记录用于回看已参与的小事；按钮、空状态、加载提示和无障碍名称使用同一口径。内部类型与数据标识不改名。
- 手册共用标题、关闭按钮与纸页书签导航，默认打开心愿计划；首次引导统一从应用入口启动，手册内保留主动填写与「使用指南」入口。栏目切换保留未保存表单和当前查看位置，普通编辑保存喜好后显示就地反馈。
- 支持左右方向键及 Home/End 切换页签、Esc 关闭、焦点返回原入口；仅当前栏目可见和可交互。未填写喜好的提示收进手册入口与喜好页签，不再覆盖首页内容。
- 长程详情以“愿望 → 章节 → 真实成果”组织信息。
- 保留奶油纸底、moss 绿与橙色书脊；封面不使用虚构成果图。桌面双列封面，手机单列；章节用虚线串联，完成节点实心盖章。
- 创建页收集愿望、动机、喜好、雷点、时长和场景。生成后展示全部章节与证物标准，用户确认后启用。关闭页面保留输入；服务失败明确提示并允许重试。
- 任务卡展示所属长程、章节序号、意义及前序成果摘要。正文与证物保留完整，不能为紧凑布局隐藏关键验收要求。
- 详情页区分“下一章／以后慢慢来／已经留下”，暂停与续接始终使用软节奏文案。处于另一条执行任务时暂不启动新章节。
- 第一章、过半和全部完成解锁专属纪念章；完成弹层显示本次长程进度与奖励，刷新恢复不重放旧奖励。
- 成果页按章节保留原始文字、照片与完成日期；文字下载包含照片链接。未完成章节展示未来计划，不伪装为已完成记录。
- 输入字号至少 16px、按钮至少 44px；弹层适配可见视口和安全区，支持 Esc 关闭、焦点圈定与焦点返回。
- 示例入口先填表，允许调整，再预览；草稿可返回修改并在同一目标下重新生成。生成失败保留输入，已开启计划不允许覆盖。
- 创建与修改心愿只展示「我的愿望」一个文本框，删除动机、目标偏好、雷点、时长与场景表单。AI 结合已保存的喜好档案制定具体章节；普通生成使用 15 分钟、场景不限的碎片任务默认值，不提交旧缓存里不可见的补充字段。示例入口仍可预览预设计划；真正开始章节时再选择当下时间和场景。
- 日常记录为空时展示最多六枚真实未解锁成就及其解锁条件，保留未获得状态，不伪装成果。提供「去开启一条支线」快捷按钮：新用户获得推荐，已有会话返回当前支线；有请求进行时禁用，避免重复启动。
- 推荐卡、聊天步骤、任务抽屉及通话卡片共用前序成果纸条：展开后显示原始文字、完成日期和原图入口；不把摘要当作完整作品。
- 后续未解锁章节明确显示「完成第 N 章后解锁」，保留查看计划的能力。

### 应用级首次引导

- 首次打开应用，在会话恢复、喜好、日常记录与心愿查询完成后判断是否为新用户。无已有会话、喜好或心愿及日常记录时自动进入应用级引导；老用户不强制重走。查询失败时保留正常应用入口。
- 全局流程缩短为四页：「认识吱呀（包含一个对话示例）→ 记下喜好（可选）→ 种下心愿（可选）→ 启程」。移除例子后重复的聊天、选卡、提交、手册四页演练。使用整页纸张布局、短淡入动效与四段进度；正文独立滚动，顶部保留跳过。
- 开场按「白天工作、晚上疲惫刷手机 → 偶尔感到空虚无聊 → 为自己经营支线任务 → 吱呀帮忙想活动、引导第一步」逐句展开。只保留周末独自在家的桌上小物展，删除朋友等车示例及末尾重复的手册/填写说明；邀请用户告知地点、时间、同行者、喜好与雷点后直接显示喜好填写入口。
- 默认演练活动为「给桌上的小物办个展」：挑两件物品、摆成微型展览、起展名并写一句展签。示例《今晚暂停营业》用钥匙和合上的笔记本表达下班后的休息；欢迎字幕、推荐卡、操作说明、提交示例与手册记录保持同一活动，不再使用找三种绿色的示例。
- 例子采用连续对话：发送预设开场话后保留「你」的气泡，吱呀回复并给出推荐；任务标题在左、小号「认领任务」按钮在右，标题允许换行，取消卡片与按钮外层装饰描边。认领后直接显示吱呀的第一步，删除自动生成的「就选这个，怎么开始？」消息。作品默认填好且只读，无需输入或验证。点击「发送示例作品」后，将同一段文字放入用户气泡，吱呀回应并说明正式使用可到「我的手册」回看。每次操作后的前文都保留，角色左右区分，最新响应轻淡入并滚动到可见处。
- 当前操作用绿色细描边和两轮轻扩散提示强调；例子明确标注「对话演示」，不调用模型、不创建会话、不伪装真实验收。真实推荐、验收与存档从最终明确启动后开始。
- 减少动态效果时取消位移、扩散与等待动画，保留静态描边、箭头和完整文字；操作前后的状态变化仍然可见。所有按钮可通过键盘操作，语音权限不在演练中申请。
- 讲解采用无外框的整句字幕：取消逐字打字与光标，整句用 0.8 秒透明度淡入，不增加位移动画；每句切换比上一版提前 2 秒，总时长为 0.8 秒 + max(3.5 秒, 字数 × 90ms) − 2 秒，短句约 2.3 秒。旧句替换而非累积。开场字幕按句在居中、靠左、靠右的位置切换；位置只在换句时变化，操作区保持稳定。手机缩小横向位置差，减少动态效果时直接显示完整句子并手动推进。
- 示例仅标注「对话演示」。开场输入改为三行圆角文本框，完整展示默认示例，保留苔藓绿圆形纸飞机发送键；16px 输入默认填好示例，发送键独立可点击且不小于 44px。发送键持续以 1.4 秒一轮加深背景、增强光晕，纸飞机放大至 1.25 倍并上浮 4px；外围 2px 圆环向外扩散 10px，直到点击。点击热区稳定，减少动态效果时关闭。
- 喜好填写前先展示一页介绍：以下班后的十五分钟为例，解释不同节奏和玩法偏好如何影响推荐，以及兴趣与雷点会存入喜好档案。点击「开始选一选」后才展示题目；仍可稍后填写。
- 「认领任务」「发送示例作品」与发送键共用同一套 1.4 秒循环动效：苔藓绿背景加深、光晕增强、2px 轮廓向外扩散 10px；文字上浮 4px、放大至 1.1 倍。轮廓沿按钮形状扩散，胶囊按钮不按宽度成倍缩放，避免手机溢出。取消单独的透明度闪烁；减少动态效果时统一关闭，键盘焦点保留清晰描边。
- 发送示例作品后，底部立即将暂停/跳过替换为「再看一遍」和「下一步」，滚动显示操作区。「下一步」进入喜好介绍；「再看一遍」重置当前演示，从默认多行输入重新开始，无需重播开场字幕，不创建个人记录。
- 进入演示后自动播放停止推进，底部只保留一个「跳过」胶囊按钮，进入喜好介绍；不再显示暂停与跳过字幕两个图标。作品内容仅为本次演示，不伪装成持久化成果。
- 讲解与导航控制放在正文中、紧跟当前内容，不使用固定底栏或 footer。字幕阶段播放控制为居中的两个 48×48px 圆形图标按钮，间隔 16px：「暂停 / 继续播放」与「跳过这一步」。跳过这一步仅推进当前字幕；进入演示后替换为单个「跳过」，演示完成后替换为「再看一遍 / 下一步」。顶部「跳过引导」用于退出。图标按钮提供 aria-label 和 title；减少动态效果时暂停按钮禁用。切到后台暂停计时，表单页保留内部上/下一题，外层仅提供「这项稍后再填」。
- 引导顶栏、正文内控制与演示操作统一使用全圆角：文字按钮为胶囊，等宽高图标按钮为圆形。「再看一遍」「下一步」使用相同字号、内边距与形状，主操作苔藓绿、次操作浅绿；不混用方角、圆角矩形与裸文字操作。
- 引导范围（包含真实喜好与心愿表单）统一使用 LXGW WenKai 文楷，Noto Sans SC 为加载失败时的后备；不混用快乐体、毛笔手写体。此范围按用户最新要求覆盖前文按钮字体约束。标题 22–24px、字幕 18–20px、正文与输入 16px、提示 12px；用字号和颜色分层。
- 引导采用手机优先的宽度规范：内容列最大 480px，手机不加外框；顶栏、进度、正文和正文内控制共用 16px 页边距。字幕仅保留 8px 的横向位置变化空间，不叠加内层容器缩窄正文。手机标题 20px、字幕 18px、试用字幕与输入 16px，长句自然换行。
- 手机页面内主操作、示例作品发送使用满宽或填满剩余宽度的 48px 按钮；其余点击热区至少 44×44px。试用卡片 12–16px 内边距；360px 以下选填字段改为单列。横屏内容仍限制在 480px 内。
- 引导与应用共用 visualViewport 高度和 `--app-height`；可见高度低于 600px 时缩小吱呀，低于 450px 或手机试用展示默认作品时缩至 64px。正文与控制一起滚动，不能由固定底栏遮挡对话。横向安全区由 App 外层统一处理，顶底留安全区。
- 奶油纸底、浅色卡片、苔藓绿为统一视觉体系：外框圆角 24px、卡片 16px、控件 12px、1px 描边；取消倾斜卡片、厚书脊、印章装饰与嵌套纸张背景。只保留顶栏全局进度，去掉正文重复页码；喜好题号保留文字，移除第二条进度条。首尾使用同一吱呀形象。
- 首页与「我的手册」均有「使用指南」，聊天和沉浸模式可经手册访问。重看不清除会话、证物或计划。引导中不自动申请定位或麦克风；定位改为真正开始支线后请求。
- 全局页码与结束状态使用 `xian-app-guide-v1:${clientId}` 持久化；内部保留 0/5/6/7 以兼容喜好与心愿续填，旧演练页 1–4 恢复时回到新版开场。进行中刷新回到原页；跳过或完成后不自动弹出。旧用户标为 existing。每一项填写均可跳过；最后确认开场话后开启真实支线。已有会话重看结束时返回原会话。
- 喜好分为 6 个短页：活动强度、新鲜感、社交、预算、玩法、兴趣与雷点。前四题单选后保留 260ms 的选中反馈，自动进入下一题；快速改选以最后选择为准，返回或退出取消待跳转。可返回上一题修改或「留白，下一题」跳过；第一题可返回介绍。玩法多选和文字补充保留手动继续，最后明确保存。普通喜好编辑保持完整表单，时间对比仍可使用。
- 应用引导中的心愿页只收集愿望，提供可点击的文字灵感。「记下心愿」保存成功后仅展示原始愿望和「心愿已记下」确认，不展示 AI 标题、章节、步骤、证物要求和纪念章；点击「记好了，继续」进入启程页。计划保留为草稿，用户之后从手册查看并确认开启。手册内的计划预览仍保持完整。最终启程按钮统一为「开始体验」，已有会话返回应用，新用户开启推荐；不声称跳过的资料已保存或任务已完成。
- 手册取消独立的首次自动弹出，避免两套引导重复出现。「继续填写引导」仍可主动进入喜好与心愿填写；「稍后再填」和切换栏目均退出局部填写引导，重新打开手册需要主动续填。
- 首次喜好的介绍完成状态、未保存答案与题号缓存在 sessionStorage，刷新后续填，保存后清除；心愿沿用草稿缓存与服务端计划恢复。关闭标签页后未保存的临时输入不保证保留；已保存档案和计划由后端持久化。
- 失败保留输入并显示错误，不误报保存成功；保存期间退出引导，不因迟到的成功结果重新拉回。示例与灵感仅填表，不自动生成个人记录。
- 动效采用短淡入、进度条变色与当前步骤两次轻呼吸，不循环催促；遵循系统减少动态效果设置。窄屏与横屏的正文内控制可滚动到达。
- 验证入口：隔离 fixture `tests/goal-preview.mjs` + `tests/app-onboarding-check.mjs`、`tests/library-onboarding-check.mjs`。覆盖 4 种屏幕、首次触发、玩法无写入、权限不打扰、焦点圈定、减少动态效果、保存失败、刷新续填、预览确认、跳过与重看、旧用户兼容及异步保存时退出；`tests/goal-journey-check.mjs` 验证原有完整三章流程。模型使用测试替身，真实保存通过隔离服务端路由与存储验证。
